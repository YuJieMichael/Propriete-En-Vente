Release procedure:
1. Fetch origin and create a feature branch from the latest origin/main.
2. Make the change, review its diff, and run the relevant tests and production build.
3. Open a pull request targeting main. Merge the reviewed PR without bypassing required checks.
4. Confirm the Cloudflare Workers Builds result for that exact merge commit is successful, and verify the live website. A successful GitHub merge alone is not proof of deployment. If a build fails, the previous successful website remains live until a successful release.
