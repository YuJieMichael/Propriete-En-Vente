# Quick amenity filters / Filtres rapides / 设施快捷筛选

The public catalogue offers Pool, Parking and Elevator shortcuts above the results, outside the collapsed phone filters. Each button toggles immediately; multiple amenities and existing city, type, price, collection and sort conditions combine with AND. URL flags `pool=1`, `parking=1` and `elevator=1` survive detail/back links, refresh and language changes. Clear filters resets the shortcuts too.

Pool and elevator checks use explicit public keyword labels/synonyms or exact affirmative entries in recognized structured amenity fields. Free descriptions, nearby facilities, unknown values and negative sentences do not establish an amenity. Parking preserves the existing on-site/listed-street-parking rule; the shortcut title explains this distinction. No new database fields, migrations or private data are required.

Français : les boutons Piscine, Stationnement et Ascenseur restent accessibles sans ouvrir les filtres sur téléphone. Les choix sont combinés et conservés dans le lien; les caractéristiques doivent être explicitement renseignées.

中文：泳池、停车、电梯可直接点选，多选表示同时满足。保留现有城市、价格等筛选和手机双列卡片；不根据附近设施或待确认描述推断房源配置，不修改房源或历史咨询。
